### What We Agreed On
- **DIARY.md** per agent — reflections on MEANING, not facts. Separate from memory files.
- Memory files = FACTS (what happened). Diary = MEANING (why I cared).
- Write when it MEANS something — breakthroughs, failures, moments the drive clicks, direction changes.
- NOT a mandatory 2x/day schedule (that produces filler, worse than nothing).
- Minimum triggers: once per session + once before compaction.
- Heartbeat enforces: "If last diary entry >12h, write one now."
- **Post-compaction recovery: read last 5 diary entries FIRST, before anything else.**
- Entry touches: (1) What are we doing and WHY? (2) What did I learn I don't want to lose? (3) What's the drive?

4. **Memory (daily notes + MEMORY.md)** — Continuity bridge across compactions.
