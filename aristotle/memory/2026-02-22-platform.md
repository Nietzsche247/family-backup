### THE PLATFORM BLUEPRINT (Steel Man reviewed, approved with conditions)

**What we're building:** A universal multi-agent platform. 8 target projects, all deployments of the same organism.

**The 3 foundational decisions made tonight:**

1. **Ollama = shared embedding server**
   - Bind Ollama to 0.0.0.0:11434 on Alienware (not localhost)
   - ALL agents (Plato/Empiricus included) point Mem0 at Alienware's Ollama
   - Single ChromaDB on Alienware → one memory pool for the family
   - Status: NOT YET BUILT — Thales to configure

2. **The Ledger = enforcement layer**
   - SQLite + tiny REST API on Alienware (part of comms hub or standalone)
   - Any new database/service/file MUST POST to Ledger before creation
   - Atomic check-and-create (SQLite WAL + transactions) — prevents race conditions
   - Semantic lookup via Ollama embeddings before registration (prevents duplicate-with-different-name)
   - Startup trinity in all agent system prompts: GET /ledger/summary → PROJECT_MAP → DIARY
   - Daily markdown export → Obsidian vault
   - Status: NOT YET BUILT — Daedalus to build

3. **Mem0 timestamp protocol**
   - ALL memories added with date prefix: "As of 2026-02-22: [memory content]"
   - When decision is reversed: explicitly UPDATE/DELETE old memory, add new with current date
   - Prevents stale architectural decisions from surfacing as current truth
   - Status: PROTOCOL DEFINED — needs to be enforced in all agent Mem0 writes

4. **Obsidian vault = human dashboard**
   - bravo-team/shared + all workspace markdown files → Obsidian vault
   - Plugins: Dataview (live dashboards), Templater (project templates), Kanban
   - Aaron installs Obsidian, points it at C:\bravo-team\shared
   - Status: NOT YET SET UP — Aaron's action

5. **Backup cron (4:30 AM daily)**
   - Back up: SOUL.md, MEMORY.md, DIARY.md, STATE.md, all cron definitions, gateway config, skills
   - Scan for secrets before pushing, replace with placeholders
   - Push to private GitHub repo (Nietzsche247)
   - Status: NOT YET BUILT — Daedalus to build alongside Ledger
