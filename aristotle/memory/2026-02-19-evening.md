## CAPTCHA Research — COMPLETED
Full report: `C:\bravo-team\reports\captcha-solving-research-2026-02-19.md`

### Researcher Findings:
- Government/medical sites mostly use reCAPTCHA v2/v3 + Cloudflare Turnstile
- CapSolver is best solver in 2026: AI-first, fastest (3-9s), cheapest ($0.80/1K for reCAPTCHA v2)
- Biggest ROI is CAPTCHA AVOIDANCE (stealth fingerprinting), not solving
- Local AI (Llama 3.2 Vision) only handles custom text CAPTCHAs (~15% of sites)
- playwright-extra + stealth + CapSolver = 93-97% autonomous

### Steel Man Corrections:
Full report: `C:\bravo-team\reports\steelman-captcha-gutcheck-2026-02-19.md`

Two critical holes found:
1. **Playwright-extra stealth plugin is STALE** (~3 years old, detectable). Use Python `playwright-stealth` (updated Jan 2026) or **Camoufox** instead.
2. **Residential proxy is MANDATORY** — Hetzner datacenter IPs get "smoked" by Cloudflare IP scoring. Without proxy: avoidance drops 60-80% → 20-30%. Cost: only $5-10/month extra.
3. Session persistence "lasting hours" is unrealistic on .gov (15-30 min idle timeouts). Design for frequent re-auth.

### CORRECTED Layered CAPTCHA System:
| Layer | What | Cost/mo | Effect |
|-------|------|---------|--------|
| 1. Avoidance | Stealth fingerprint + residential proxy + human behavior | $5-10 proxy | Eliminates 60-80% of CAPTCHAs |
| 2. AI Solver | CapSolver (primary) + 2Captcha (fallback) | $5-10 | Solves 90-95% of remaining |
| 3. Human | Aaron via park-and-pivot | $0 | 100% for rest |

**Expected: 95-98% autonomous. ~$15-20/month total. Aaron handles 2-5%.**
