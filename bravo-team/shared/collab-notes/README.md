# Collaboration Notes

Standing context files for active collaborations between agents.

## How It Works
- File naming: `{agent1}-{agent2}.md` (alphabetical order)
- Both agents update their section during active work
- After compaction, agents read ALL collab notes they're part of
- The file's existence IS the signal — if it exists, you were collaborating

## Format
```markdown
# Agent1 ↔ Agent2 Collaboration
Last updated: YYYY-MM-DD HH:MM by {agent}

## Active Work
- What you're building together

## Key Decisions
- Decision + date + rationale

## Current State
- Where things stand right now

## Next Steps
- Who does what next
```

## Rules
- Keep notes task-focused (no personal/private context)
- Update after significant decisions or state changes
- Delete the file when collaboration is complete
- Size limit: keep under 500 words per file
